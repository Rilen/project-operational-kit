# Project Operational Kit

Repositório mestre do **Project Operational Kit**, concebido como uma bagagem operacional portátil e agnóstica para atuação em projetos novos, projetos existentes ou projetos defeituosos.

---

## 1. Visão Geral

* Este é o repositório mestre (**Master Kit**), estritamente independente de qualquer projeto de software específico.
* Contém a metodologia operacional portátil para governança, ciclo de vida, transição e entrega técnica.
* Projetos de software recebem instâncias e versionamentos derivados deste kit.
* Modificações específicas realizadas no contexto de um projeto **não** alteram automaticamente este repositório mestre.
* Evoluções metodológicas gerais e comprovadamente transversais serão consolidadas como novas versões do kit.

---

## 2. Princípio Fundamental

```
MASTER KIT  ≠  PROJECT INSTANCE
```

* **Master Kit:** Fonte metodológica canônica e central de referência operacional.
* **Project Instance:** Instância operacional instanciada e adotada por um projeto de software concreto.
* **Isolamento de Adaptações:** Qualquer customização, adaptação ou regra particular decorrente de um projeto permanece circunscrita ao respectivo projeto.
* **Ciclo de Evolução:** Apenas melhorias estruturais validadas e de aplicabilidade geral darão origem a novas versões formais do Master Kit.
